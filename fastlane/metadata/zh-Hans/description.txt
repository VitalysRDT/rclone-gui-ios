Rclone GUI 是一款基于 rclone 打造的原生开源 iOS 客户端，可直接管理个人云存储，无需经过开发者的中转服务器。

面向中国常用对象存储
可直接连接七牛云 Kodo、阿里云 OSS、腾讯云 COS、华为云 OBS、UCloud US3，以及其他兼容 S3 的对象存储。也支持 Amazon S3、Backblaze B2、Cloudflare R2、Storj、Wasabi、Dropbox、Google Drive、Microsoft OneDrive、pCloud、Mega、Box、Filen、Internxt、Drime、SFTP、WebDAV 等 70 多种 rclone 后端。

公共链接、Markdown、HTML 与自定义 CDN
为文件生成 rclone 公共链接，或为每个远程存储设置自己的 CDN 基础域名。你可以一键复制原始 URL，也可以直接生成适用于 Docusaurus、博客和文档的 Markdown 图片链接或普通链接，以及 HTML 图片标签或超链接。

原生公共链接是否可用取决于对应的 rclone 后端。使用自定义 CDN 链接前，请先在存储服务商处正确配置公开访问权限、CDN 域名与路径。

醒目的上传入口
文件浏览页提供清晰易找的“+”按钮，可快速新建文件夹，或上传文件、文件夹以及“照片”App 中的图片和视频。

CRYPT 加密
整个界面围绕 rclone 的 crypt 加密功能设计：加密的远程存储会以紫色锁形图标标识；文件名和目录结构在设备上实时解密；内容仅在读取或播放时由本机 rclone 解密，不会以明文经过第三方服务器。加密核心采用 NaCl secretbox（XSalsa20-Poly1305）。

iOS“文件”App 集成
File Provider 扩展可在 Apple“文件”App 中显示你的远程存储，包括 crypt 加密存储。你可以直接打开 PDF、在不同 App 之间拖放文档，并播放云端视频或音乐。

智能照片同步
自动将新拍摄的照片和视频同步到指定云端。同步过程支持后台执行、网络中断后继续，并可根据 App 使用状态自适应调整传输速度。

引导式添加远程存储
分步向导会根据不同 rclone 后端显示相应配置项，并为 Google Drive、OneDrive、Dropbox 等 OAuth 服务提供授权说明和即时校验。“如何获取凭据”说明卡片和远程存储选择器可协助配置 crypt、alias、union 等组合后端。你还可以导入现有的 rclone.conf；敏感凭据会迁移到 iOS 钥匙串中保存。

为隐私而设计
- 无分析统计、无跟踪器、无第三方广告 SDK
- 无开发者后端服务器，App 直接连接你的云服务
- 可使用 Face ID 或 Touch ID 锁定配置
- 配置数据采用 ChaCha20-Poly1305 加密存储
- OAuth 凭据保存在 iOS 钥匙串中，不写入 UserDefaults
- 严格遵循 ATS（App Transport Security），不设置网络安全例外

更多功能
- 支持 70 多种 rclone 后端
- 并行传输、暂停、继续与任务队列
- 针对蜂窝网络和 Wi-Fi 的自适应带宽限制
- 支持分段请求的视频和音频流媒体播放
- 内置 Quick Look 预览
- 文件夹内搜索、排序与筛选
- 详细的传输统计信息
- 可导出的本地调试日志

PREMIUM 与购买
App 内会显示当前可用的 Premium 方案、试用资格，以及你所在地区的实际价格。购买和订阅由 Apple 处理；如选择自动续订方案，可随时前往“设置 → Apple 账户 → 订阅”管理或关闭自动续订。
